# NotiChat for iOS

Нативный iOS-клиент мессенджера **NotiChat**, полностью совместимый со своим Android-аналогом.

## Особенности
- **100% совместимость с Android**: одинаковое сквозное шифрование RSA-2048 + AES-256-CBC (`CryptoUtils`).
- **Сетевой транспорт**: мгновенная доставка через защищенные каналы `ntfy.sh` (автоматическая генерация уникального SHA-256 топика для каждого публичного ключа).
- **Нативный интерфейс iOS (SwiftUI)**:
  - Список чатов с поиском и удалением свайпом
  - Диалог сообщений в стиле iMessage / Telegram
  - Профиль с генерацией QR-кода публичного ключа и быстрым копированием
  - Быстрое создание нового чата по публичному ключу
- **Уведомления**: локальные баннеры + виброотклик и звук при входящих сообщениях.

## Как получить готовый .IPA:
1. Залей эту папку `NotiChat-iOS` в свой репозиторий на GitHub.
2. Во вкладке **Actions** запусти workflow **Build NotiChat iOS IPA** (или он запустится сам при пуше).
3. Через 2-3 минуты скачай готовый файл `NotiChat.ipa` из раздела **Artifacts** или **Releases**.
4. Перетяни скачанный `NotiChat.ipa` в окно **Sideloadly** на компьютере и нажми **Start**!
